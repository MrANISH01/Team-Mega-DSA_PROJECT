Closest Pair of Points

Brute-Force O(N²) vs Divide-and-Conquer O(N log N): plot, strip, running time and step-by-step animation.

1. Input

Points are generated in the browser (x, y in 0–100). The same seed gives the same points, so results are repeatable.

2. Output

Press “Generate & run”.

If several pairs are tied for the smallest distance, the two algorithms may report different pairs with the same distance.

Each size uses a fresh random point set (median of several runs). Doubling N should roughly quadruple the brute-force time but only a little more than double the divide-and-conquer time.

5. Corner cases & agreement check

    How divide-and-conquer works

    1. Sort the points by x and by y once.
    2. Divide: split the x-sorted list in half with a vertical line.
    3. Conquer: solve both halves recursively. Let d = min(dleft, dright).
    4. Combine: a closer pair could straddle the line, so look only at points within d of it (the strip), in y order.
    5. Each strip point needs comparing with at most 7 others (those less than d above it), so the combine step is O(N) and the total is O(N log N).
